# 电源与稳定性

[文档导航](README.md) · 实现：[main.c](../src/main.c)、[telemetry.c](../src/telemetry.c)、[epd.c](../src/epd.c)

价签需要保持可发现，同时避免应用无效轮询和屏幕长时间带电。本项目采用事件等待、两阶段广播和刷新后立即关电；这些策略已有实现，但目前没有整板电流或续航结论。

## 主循环何时醒来

| 事件/期限 | 行为 |
| --- | --- |
| 命令或连接变化 | 信号量立即唤醒，处理命令或清理旧连接 |
| 启动/断连后的 30 秒 | 快广播 100–150 ms，之后固定 1 秒慢广播 |
| 广播切换失败 | 5 秒后重试，保留原快速阶段截止时间 |
| 已连接且 120 秒无被接受业务 | 主动断开 |
| 图像或配置传输 30 秒无包 | 取消未完成事务 |
| 未连接每五分钟 | 采样并更新广播遥测 |
| 其他期限更远时 | 最多等待 60 秒，保证主循环喂狗 |

连接期间不切换快慢广播，断连开始新的快速窗口。版本查询、认证握手、被拒请求和链路保活不续业务空闲期限；被接受的业务命令才续期。同步刷新处理完后再检查空闲期限，不会在正常刷新中途被该逻辑切断。

Zephyr 的 Tickless/RTC 与信号量等待让主线程在无工作时休眠，无线和 RC 校准仍会唤醒 CPU。应用五分钟遥测不等于芯片五分钟才测温：低频 RC 校准也使用 TEMP。P0.00 用于 SPI，校准的内部 RC 是本板 BLE 时钟方案的一部分。

## 屏幕关电与深睡

启动先 RESET，再尝试 `50 F7 / 02` 关闭高压，所以未上传图片时也有明确的关电动作。刷新结束和失败清理都会尝试关电；屏幕卡 BUSY 不阻止 BLE 启动，但也不能据此认定故障屏幕已经省电。

默认在关电成功后发 `07 A5`，并断开可能悬空的 BUSY 输入缓冲。下一次传输恢复输入并 RESET；关电超时不会提前发深睡。成功后再次关电直接返回。空闲时 CS/RESET 高，SCK/MOSI/DC/BS 低。

对照构建：

```sh
uv run --locked python scripts/build.py --no-epd-deep-sleep
# 恢复默认深睡构建
uv run --locked python scripts/build.py
```

两次构建覆盖相同输出目录，做对照前分别保留产物。关闭面板内部高压不等于切断整块屏幕的供电，深睡的收益要实测整板电流。没有采用 MCU System OFF，因为本板缺乏实际可用唤醒源且需要 BLE 可连接；DCDC 外围未确认，也未盲目启用。

## 温度和 VDD

采样发生在启动、快广播结束、未连接每五分钟，以及通过长度和认证检查的 `00 44` 请求。温度使用 Zephyr 共享传感器驱动，复用其锁和 HF 时钟管理，避免与 RC 校准争用。

ADC 使用内部 VDD/3 输入、1.2 V 参考和 10 位结果，不依赖外部电池采样电路。温度编码为半度偏置值，电压按 10 mV 的 9 位值写入 MSD；保留其他状态位。只有温度与 ADC 都成功，才整体提交新快照；失败保留旧值，请求路径返回 NACK。

ADC 成功或 50 ms 超时后均停止并禁用。TEMP 驱动正常结束会停外设，但其等待没有独立超时，卡死由看门狗恢复。VDD 是电源电压代理，不能直接换算容量百分比。

## 两条恢复路径

主循环直接配置 nRF 硬件看门狗为 180 秒：睡眠时继续计数，调试器 halt 时暂停。只从主业务循环喂狗，独立心跳线程不能替代业务推进。阈值需要覆盖 60 秒空闲等待及有界的面板失败清理；把它简单缩为单次 30 秒 BUSY 超时会误伤合法恢复路径。

栈哨兵等 fatal 错误进入自定义 handler，执行冷复位。硬件看门狗另负责无法正常回到主循环的卡死，例如 TEMP 等待或关中断死循环。两者都不等于消除了触发错误的根因。

故障注入脚本通过关中断死循环验证看门狗路径，在复位前结束调试会话，避免复位后
再次halt干扰无线时序。运行前须检查匹配ELF和RAM空间；前提见 [验证指南](validation.md)。
单次恢复成功不能替代长期独立供电验证。

## 如何测功耗与稳定性

测电流前结束调试会话、断开调试连接并完整断电再上电，避免 nRF51 调试状态影响结果。依据为 [Nordic nRF51 电流测量指南](https://devzone.nordicsemi.com/guides/hardware-design-test-and-measuring/b/nrf5x/posts/nrf51-current-consumption-guide)；其中示例值不代表本板。

固定供电电压、温度、图片、无线距离和连接条件，用可捕获无线/升压脉冲的仪器测量：

| 状态 | 应报告 |
| --- | --- |
| 冷启动与前 30 秒快广播 | 峰值、电荷、是否可靠发现 |
| 稳定慢广播 | 覆盖 RC 校准和五分钟遥测周期的均值、峰值、谷值 |
| 连接空闲至主动断开 | 实际连接间隔、期间电荷、断开后的恢复 |
| 全刷、单局刷、两步局刷 | 相同完整时间窗内的总电荷及刷新电荷 |
| 仅关电与深睡 | 稳态差值、连续唤醒和画质 |

性能更快或 PC 更多落在 WFI，不足以推算耗电更低。续航估算还需要电池有效容量、脉冲压降、温度、自放电和截止电压。

稳定性验证另做：独立供电冷启动、周期连接、上传截断、主动断线、BUSY 故障与恢复后再上传；记录重启原因、失败次数和恢复时间。至少 24 小时可作为起点，但不是可靠性认证。真实 Flash 擦写瞬间掉电和低电压刷新仍属于待补证据，不能用 SWD 复位替代。
