## 如何理解文档中的结论

设计说明以本仓源码为依据；协议兼容性以项目固定的 OpenDisplay Firmware `7c9413edd9f7fa16e714f6ebc00b76efd3bad4eb` 和 py-opendisplay 7.14.1 为基准。依赖版本以 `west.yml`、`uv.lock` 为准，不把上游最新行为自动套用到此版本。

实机数据是指定构建和负载的观测，不是所有版本、面板和温度的保证。本文档重写整理了 2026-09-07 至 2026-09-16 的已有记录，没有因此新增硬件验证。原始实验脚本、日志和备份中的一部分只在本地忽略目录 `build/`，全新检出不能依赖它们运行；可复用的验证入口均指向已跟踪的 `scripts/` 或 `tests/`。

修改行为时更新对应主题；新增实验只补充影响设计判断的条件、结果和限制。旧版执行记录可从 Git 历史查阅。
